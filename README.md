## Selected portfolio projects

### Corporate Carbon Footprint and GHG Inventory
Developed a portfolio GHG inventory covering Scope 1, Scope 2 and selected Scope 3 sources using activity data and emission factors. Calculated **341.44 tCO2e**, identified grid electricity as **50.3%** of emissions, and documented assumptions, limitations and proposed reduction measures.

### Indian Corporate BRSR Sustainability Analytics Dashboard
Structured environmental data from public BRSR disclosures across Indian companies and financial years. Built a Power BI model and DAX measures to analyse Scope 1-3 emissions, carbon intensity, trends and hotspots.

### Scope 3 Value-Chain and Product Materiality Carbon Model
Built an Excel model for selected upstream materials and downstream logistics using GHG Protocol and LCA concepts. Used XLOOKUP and PivotTables to consolidate emissions calculations and support traceable review.
